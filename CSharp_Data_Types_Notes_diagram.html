C# Data Types and Core Concepts (Visual Notes)

1. Value Types and Reference Types

Concept: Value types store actual data directly in memory, while reference types store a pointer (address) to where the data is kept. Value types live on the Stack; Reference types live on the Heap (with their pointer on the Stack).

2. Boxing and UnBoxing

Concept: Boxing wraps a stack-based value type inside a heap-based object. Unboxing extracts it back. This causes performance overhead due to memory allocation.

Value (Stack)
int i = 123;
→ (Boxing) →
Object (Heap)
object o = i;
→ (Unboxing) →
Value (Stack)
int j = (int)o;

4. Nullable Types

Concept: Value types cannot natively be null. Nullable types (T?) wrap the value type with a boolean flag indicating if it actually holds a value.

int? x = null;
HasValue: false
Value: [empty]
vs
int? y = 5;
HasValue: true
Value: 5

5. Implicitly Typed Variables (var) & 6. Var vs Dynamic

Concept: var is strongly typed but figured out by the compiler. dynamic bypasses compile-time checks entirely and resolves at runtime.

var x = 10;
(Compiler locks as INT)
→ Compile Time →
int x = 10;


dynamic y = 10;
(Compiler ignores)
→ Run Time →
Checks type in memory

7. 'is' and 'as' Operators

Concept: Safe type casting. is returns a boolean. as performs the cast or returns null.

if (obj is string) → Returns TRUE or FALSE

string s = obj as string; → Returns STRING or NULL

8. Ref vs Out Keywords

Concept: Both pass references, not values. ref is for 2-way data flow (in and out). out is for 1-way data flow (out only).

Caller (Initialized)
↔ (ref) ↔
Method


Caller (Uninitialized)

9. Object Base Class & 10. Equals() vs ==

Concept: == checks reference identity for objects (do they point to the exact same memory?). Equals() is often overridden to check value identity (do they contain the same data?).

11. String vs StringBuilder

Concept: Strings are immutable (cannot change). Concatenation creates dead memory copies. StringBuilder maintains an expanding buffer.

String (s += "a"):
"s" (Discarded)
→
"sa" (Discarded)
→
"saa" (Active)


StringBuilder (Append):
[s, a, a, _, _] (Expands)

14. Parse() vs TryParse() vs Convert

Concept: Different ways to convert strings to numbers, with different error handling.
