Q1.1

Struct vs Class: The Copy Detective

Medium
Create a struct PointS and a class PointC, each with public int X, Y fields. Write two methods MoveS(PointS p) and MoveC(PointC p) that add 10 to X. Call both and print the caller's values before and after, to prove which type is copied and which is shared.
Requirements
  • Both types must start at (1, 2)
  • Print the values before and after each method call
  • Then assign var s2 = s1; and var c2 = c1;, change s2.Y and c2.Y to 99, and print the originals
Expected output
Before  -> struct: (1,2)  class: (1,2)
After   -> struct: (1,2)  class: (11,2)
Assign  -> s1.Y = 2, c1.Y = 99
Gotcha
Changing a struct parameter inside a method never reaches the caller unless you pass it with ref.
Hint
A struct parameter receives a copy of all its fields. A class parameter receives a copy of the reference, so it still points at the same object.
Show solution
Program.cs · complete, runnable
var s1 = new PointS { X = 1, Y = 2 };
var c1 = new PointC { X = 1, Y = 2 };

Console.WriteLine($"Before  -> struct: ({s1.X},{s1.Y})  class: ({c1.X},{c1.Y})");
MoveS(s1);
MoveC(c1);
Console.WriteLine($"After   -> struct: ({s1.X},{s1.Y})  class: ({c1.X},{c1.Y})");

var s2 = s1; s2.Y = 99;
var c2 = c1; c2.Y = 99;
Console.WriteLine($"Assign  -> s1.Y = {s1.Y}, c1.Y = {c1.Y}");

static void MoveS(PointS p) => p.X += 10;
static void MoveC(PointC p) => p.X += 10;

struct PointS { public int X, Y; }

Swap That Doesn't Swap

Medium
Write SwapNoRef(int[] a, int[] b), which swaps its two parameters with a temp variable, and SwapWithRef(ref int[] a, ref int[] b), which does the same with ref. Call both on x = {1,2,3} and y = {7,8,9} and print the arrays after each call. Then write SwapFirst(int[] a, int[] b), which swaps only element [0], and show that this does affect the caller without ref.
Requirements
  • Use string.Join(",", arr) to print the arrays
  • Explain in a comment why SwapNoRef fails but SwapFirst works
Expected output
After SwapNoRef   : x=[1,2,3] y=[7,8,9]
After SwapWithRef : x=[7,8,9] y=[1,2,3]
After SwapFirst   : x=[1,8,9] y=[7,2,3]
Hint
Reassigning a reference-type parameter changes only the method's local copy of the reference. Changing the object it points to is visible to everyone.
Show solution
Program.cs · complete, runnable

int[] y = { 7, 8, 9 };

SwapNoRef(x, y);
Console.WriteLine($"After SwapNoRef   : x=[{string.Join(",", x)}] y=[{string.Join(",", y)}]");

SwapWithRef(ref x, ref y);
Console.WriteLine($"After SwapWithRef : x=[{string.Join(",", x)}] y=[{string.Join(",", y)}]");

SwapFirst(x, y);
Console.WriteLine($"After SwapFirst   : x=[{string.Join(",", x)}] y=[{string.Join(",", y)}]");

// Reassigns only local copies of the references -> caller unaffected
static void SwapNoRef(int[] a, int[] b) { var t = a; a = b; b = t; }

// ref passes the caller's variables themselves -> real swap
static void SwapWithRef(ref int[] a, ref int[] b) { var t = a; a = b; b = t; }

// Mutates the shared heap objects -> caller sees the change
static void SwapFirst(int[] a, int[] b) { (a[0], b[0]) = (b[0], a[0]); }

Q1.3

Shallow Copy vs Deep Copy

Hard
Create a class Order with int Id, string Customer and List<string> Items. Add ShallowCopy() (use MemberwiseClone()) and DeepCopy() (create a new list). Make one shallow copy and one deep copy of an order, add an item and change the customer through each copy, and print the original every time.
Requirements
  • ShallowCopy must return (Order)MemberwiseClone()
  • DeepCopy must copy the list with new List<string>(Items)
  • Print the original's Customer and Items after each change
Expected output
After shallow edit -> Customer: Asha, Items: Pen, Book, Bag
After deep edit    -> Customer: Asha, Items: Pen, Book, Bag
Deep copy items    -> Pen, Book, Bag, Laptop
Gotcha
Strings are reference types but immutable. Changing shallow.Customer points the copy at a new string and leaves the original alone. Only the shared mutable list leaks.
Hint
MemberwiseClone copies field values. For the List field, that value is a reference, so both orders share one list.
Show solution
Program.cs · complete, runnable
var original = new Order { Id = 1, Customer = "Asha", Items = new List<string> { "Pen", "Book" } };

var shallow = original.ShallowCopy();
shallow.Customer = "Ravi";
shallow.Items.Add("Bag");
Console.WriteLine($"After shallow edit -> Customer: {original.Customer}, Items: {string.Join(", ", original.Items)}");

var deep = original.DeepCopy();
deep.Customer = "Meena";
deep.Items.Add("Laptop");
Console.WriteLine($"After deep edit    -> Customer: {original.Customer}, Items: {string.Join(", ", original.Items)}");
Console.WriteLine($"Deep copy items    -> {string.Join(", ", deep.Items)}");

class Order
{
    public int Id;
    public string Customer = "";
    public List<string> Items = new();

    public Order ShallowCopy() => (Order)MemberwiseClone();

    public Order DeepCopy()
    {
        var copy = (Order)MemberwiseClone();
        copy.Items = new List<string>(Items);
        return copy;
    }
}

Q1.5

Mutable Structs in a List

Hard
Create struct StockItem { public string Sku; public int Qty; } and a List<StockItem> with 3 items. Write Restock(List<StockItem> items, string sku, int add), which increases the quantity of the matching SKU. Note that items[i].Qty += add; does not compile, so use the read-modify-write pattern instead. Then do the same with a StockItem[] array, where arr[i].Qty += add does compile.
Requirements
  • Inventory: P100=5, P200=0, P300=12
  • Restock P200 by 20 in the list, and P300 by 3 in the array
  • Print both collections
Expected output
List : P100=5 | P200=20 | P300=12
Array: P100=5 | P200=20 | P300=15
Gotcha
Running foreach (var it in list) it.Qty++; is also a compile error, because the foreach iteration variable is read-only.
Hint
The list indexer returns a copy of the struct, so editing it would change a temporary value (error CS1612). An array element is a storage location, so you can edit it in place.
Show solution
Program.cs · complete, runnable
var list = new List<StockItem>
{
    new() { Sku = "P100", Qty = 5 },
    new() { Sku = "P200", Qty = 0 },
    new() { Sku = "P300", Qty = 12 }
};
Restock(list, "P200", 20);
Console.WriteLine("List : " + string.Join(" | ", list.Select(i => $"{i.Sku}={i.Qty}")));

StockItem[] arr = list.ToArray();
for (int i = 0; i < arr.Length; i++)
    if (arr[i].Sku == "P300") arr[i].Qty += 3;   // allowed on arrays
Console.WriteLine("Array: " + string.Join(" | ", arr.Select(i => $"{i.Sku}={i.Qty}")));

static void Restock(List<StockItem> items, string sku, int add)
{
    for (int i = 0; i < items.Count; i++)
    {
        if (items[i].Sku != sku) continue;
        var item = items[i];   // 1. read (copy)
        item.Qty += add;       // 2. modify the copy
        items[i] = item;       // 3. write it back
    }
}

struct StockItem { public string Sku; public int Qty; }

Q2.1

ArrayList vs List<int>: Measure the Cost

Medium
Fill an ArrayList and a List<int> with the numbers 1 to 5,000,000. Sum each one and time both the fill and the sum with Stopwatch. Use GC.GetAllocatedBytesForCurrentThread() to print how many megabytes each collection allocated.
Requirements
  • Use long for the sums
  • Print both sums (they must be equal), plus the time and MB for each
  • Add a comment showing where the boxing and the unboxing happen
Sample output (timings and sizes will differ on your machine)
ArrayList : sum=12500002500000  time=1040 ms  alloc=242 MB
List<int> : sum=12500002500000  time=366 ms  alloc=64 MB
Gotcha
Run benchmarks in Release mode (dotnet run -c Release), or the timings will mislead you. The allocation numbers are reliable either way.
Hint
ArrayList.Add(object) boxes every int into a new heap object. Reading it back needs an (int) unbox.
Show solution
Program.cs · complete, runnable
using System.Collections;
using System.Diagnostics;

const int N = 5_000_000;

long before = GC.GetAllocatedBytesForCurrentThread();
var sw = Stopwatch.StartNew();
var al = new ArrayList();
for (int i = 1; i <= N; i++) al.Add(i);          // boxing on every Add
long sum1 = 0;
foreach (object o in al) sum1 += (int)o;         // unboxing on every read
sw.Stop();
long alBytes = GC.GetAllocatedBytesForCurrentThread() - before;
Console.WriteLine($"ArrayList : sum={sum1}  time={sw.ElapsedMilliseconds} ms  alloc={alBytes / 1_048_576} MB");

before = GC.GetAllocatedBytesForCurrentThread();
sw.Restart();
var list = new List<int>();
for (int i = 1; i <= N; i++) list.Add(i);        // no boxing
long sum2 = 0;
foreach (int v in list) sum2 += v;
sw.Stop();
long lBytes = GC.GetAllocatedBytesForCurrentThread() - before;
Console.WriteLine($"List<int> : sum={sum2}  time={sw.ElapsedMilliseconds} ms  alloc={lBytes / 1_048_576} MB");

Count the Hidden Boxing

Hard
Use GC.GetAllocatedBytesForCurrentThread() to measure four loops of 100,000 iterations each: (1) string.Format("{0}", i), (2) $"{i}" interpolation, (3) adding to object[], (4) adding to int[]. Print the bytes allocated per iteration for each loop, and work out which loops box.

Show solution

Measure("$\"{i}\" interp   ", () => { for (int i = 0; i < N; i++) _ = $"{i}"; });

void Measure(string label, Action body)
{
    body(); // warm-up (JIT)
    long before = GC.GetAllocatedBytesForCurrentThread();
    body();
    long bytes = GC.GetAllocatedBytesForCurrentThread() - before;
    Console.WriteLine($"{label}: {Math.Round((double)bytes / N)} bytes/iteration");
}
// string.Format(string, object) boxes i AND allocates the result string.
// Interpolation (C# 10 / .NET 6+) formats i straight into a buffer: only the result string is allocated.

static int[,] RotateClockwise(int[,] m)
{
    int rows = m.GetLength(0), cols = m.GetLength(1);
    var result = new int[cols, rows];
    for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++)
            result[c, rows - 1 - r] = m[r, c];
    return result;
}

Spiral Order Traversal

Write List<int> Spiral(int[,] m), which returns the elements in clockwise spiral order, starting at the top-left. It must handle any rectangular matrix, including one row, one column, and 4×3 or 3×4 shapes.
Requirements

  • Each element must appear exactly once (no duplicates on odd shapes)
  • Print each result as a comma-separated list
Expected output

1,2,3,6,9,12,11,10,7,4,5,8
1,2,3,4,5

Gotcha
Without the two inner if checks, a 1×5 matrix prints its row twice: once forwards and once backwards.
Hint
Keep four boundaries: top, bottom, left and right. After the top row and right column, check top <= bottom and left <= right again before walking back.
Show solution
Program.cs · complete, runnable
Console.WriteLine(string.Join(",", Spiral(Build(3, 4))));
Console.WriteLine(string.Join(",", Spiral(Build(4, 3))));
Console.WriteLine(string.Join(",", Spiral(Build(1, 5))));
Console.WriteLine(string.Join(",", Spiral(Build(5, 1))));

static int[,] Build(int rows, int cols)
{
    var m = new int[rows, cols];
    int v = 1;
    for (int r = 0; r < rows; r++) for (int c = 0; c < cols; c++) m[r, c] = v++;
    return m;
}

static List<int> Spiral(int[,] m)
{
    var res = new List<int>();
    int top = 0, bottom = m.GetLength(0) - 1, left = 0, right = m.GetLength(1) - 1;
    while (top <= bottom && left <= right)
    {
        for (int c = left; c <= right; c++) res.Add(m[top, c]);
        top++;
        for (int r = top; r <= bottom; r++) res.Add(m[r, right]);
        right--;
        if (top <= bottom)
        {
            for (int c = right; c >= left; c--) res.Add(m[bottom, c]);
            bottom--;
        }
        if (left <= right)
        {
            for (int r = bottom; r >= top; r--) res.Add(m[r, left]);

        j[r] = new int[len];
        for (int c = 0; c < len; c++) j[r][c] = m[r, c];
    }
    return j;

static string Compress(string s)
{
    if (s.Length == 0) return s;
    var sb = new StringBuilder();
    int count = 1;
    for (int i = 1; i <= s.Length; i++)
    {
        if (i < s.Length && s[i] == s[i - 1]) { count++; continue; }
        sb.Append(s[i - 1]).Append(count);
        count = 1;
    }
    return sb.Length < s.Length ? sb.ToString() : s;
}

static string Decompress(string s)
{
    var sb = new StringBuilder();
    int i = 0;
    while (i < s.Length)
    {
        char ch = s[i++];
        int n = 0;
        while (i < s.Length && char.IsDigit(s[i])) n = n * 10 + (s[i++] - '0');
        sb.Append(ch, n);
    }
    return sb.ToString();
}

static void ReverseWords(StringBuilder sb)
{
    Reverse(sb, 0, sb.Length - 1);                  // 1. reverse everything
    int n = sb.Length, start = 0;
    while (start < n)                               // 2. reverse each word back
    {
        while (start < n && sb[start] == ' ') start++;
        int end = start;
        while (end < n && sb[end] != ' ') end++;
        Reverse(sb, start, end - 1);
        start = end;
    }
    int w = 0;                                      // 3. collapse spaces in place
    for (int r = 0; r < n; r++)
    {
        if (sb[r] != ' ') sb[w++] = sb[r];
        else if (w > 0 && sb[w - 1] != ' ') sb[w++] = ' ';
    }
    if (w > 0 && sb[w - 1] == ' ') w--;
    sb.Length = w;                                  // truncate
}

static void Reverse(StringBuilder sb, int i, int j)
{
    while (i < j) { (sb[i], sb[j]) = (sb[j], sb[i]); i++; j--; }
}

static LogEntry? Parse(string line)
{

    string service = line.Substring(rb + 1, colon - rb - 1).Trim();

        while (end < message.Length && char.IsDigit(message[end])) end++;
        if (int.TryParse(message.Substring(hash + 1, end - hash - 1), out var n)) orderNo = n;
    }
    return new LogEntry(when, level, service, message, orderNo);
}

static bool IsPalindrome(string s)
{
    int i = 0, j = s.Length - 1;
    while (i < j)
    {
        if (!char.IsLetterOrDigit(s[i])) { i++; continue; }
        if (!char.IsLetterOrDigit(s[j])) { j--; continue; }
        if (char.ToLowerInvariant(s[i]) != char.ToLowerInvariant(s[j])) return false;
        i++; j--;
    }
    return true;
}

static string LongestPalindromeWord(string sentence)
{
    char[] seps = { ' ', ',', '.', '!', '?', ';', ':' };
    string best = "";
    foreach (var w in sentence.Split(seps, StringSplitOptions.RemoveEmptyEntries))
        if (w.Length > 1 && IsPalindrome(w) && w.Length > best.Length) best = w;
    return best.Length == 0 ? "(none)" : best;
}

static string MaskCard(string? card)
{
    if (card is null) return "";
    int digits = card.Count(char.IsDigit);
    if (digits < 8) return card;
    var sb = new StringBuilder(card.Length);
    int seen = 0;
    foreach (char ch in card)
    {
        if (char.IsDigit(ch)) { seen++; sb.Append(seen <= digits - 4 ? '*' : ch); }
        else sb.Append(ch);
    }
    return sb.ToString();
}

static string MaskEmail(string? email)
{
    if (email is null) return "";
    int at = email.IndexOf('@');
    if (at < 0) return email;
    string local = email.Substring(0, at), domain = email.Substring(at);
    string masked = local.Length <= 2 ? "*" : local[0] + new string('*', local.Length - 2) + local[^1];
    return masked + domain;
}

static string MaskPhone(string? phone)
{

    string rest = phone.Substring(firstSep);
    int digits = rest.Count(char.IsDigit), seen = 0;
    var sb = new StringBuilder(cc);
    foreach (char ch in rest)
    {
        if (char.IsDigit(ch)) { seen++; sb.Append(seen <= digits - 3 ? '*' : ch); }
        else sb.Append(ch);
    }
    return sb.ToString();
}
